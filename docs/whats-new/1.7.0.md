# v1.7.0 — для пользователя

- У каждого навыка теперь своя очередь: владелец, разработка, маркетинг и остальные нумеруются отдельно, и перестановка в одной очереди не сдвигает другие.
- Владелец может переставить карточку любого навыка; порядок меняется только внутри этой очереди.
- Если карточку вручную опустили в очереди, у неё растёт счётчик «демон» — в бэклоге это видно прямо в ID.
- Порядок очереди определяет, что попадёт в следующий Ран: агент советует карточки из очередей своих навыков.
- Статус ревью снова называется «ждёт финального ревью» — без двусмысленного «проходит ревью».
