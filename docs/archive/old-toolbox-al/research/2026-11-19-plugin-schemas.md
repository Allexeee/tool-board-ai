# Схемы инструментов плагина: цена в контексте

Дата: 2026-11-19. Источник: `.opencode/plugins/toolbox-al/index.ts` (сгенерирован из `src/core/opencode-plugin.txt`).

## Что посчитано

Длина всех блоков `editor.add({...})` в символах исходника. Это не точный токен-счёт: реальный размер зависит от сериализации схем хостом, но порядок величины показывает.

| | Инструментов | Символов | Оценка токенов (÷3.5) |
|---|---:|---:|---:|
| Сейчас | 14 | 4 522 | ~1 290 |
| Группы по смыслу | 3 | ~1 200 (оценка) | ~350 |
| Один `toolbox` с action | 1 | ~600 (оценка) | ~170 |

По инструментам (символов): now 209, inbox 195, task 248, take 384, done 468, block 644, tasks 196, requests 170, plan 224, ask 381, dispatch 196, review 571, accept 377, answer 259.

## Чего эти числа не показывают

Главная цена выбора — не токены схем, а ошибки: модель путает имя действия и аргументы. У одного инструмента с `action` ошибок обычно больше, чем у отдельных инструментов с явными схемами. Поэтому решение нельзя принять по байтам.

## Как решать

1. Взять 3 одинаковых набора задач (например, «взять задачу», «закрыть с отчётом», «посмотреть очередь»).
2. Прогнать в трёх вариантах плагина: 14 инструментов, 3 группы, 1 `toolbox`.
3. Считать: долю вызовов с ошибкой аргументов, число повторных вызовов, токены на схемы.
4. Выбирать по сумме: ошибки × цена исправления + токены.

Пока вывод один: 14 инструментов стоят около 1,3 тыс. токенов в каждом запросе — заметно, но не катастрофа. Группировка экономит порядка 1 тыс. токенов; если ошибок не прибавит — это чистый выигрыш.
