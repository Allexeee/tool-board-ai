# Терминология

## Термины

| Термин | Значение | Пример | Автор | Дата |
|---|---|---|---|---|
| Spec | Что и зачем нужно, границы, ограничения и критерии приёмки; контракт владельца и исполнителя. | «Нужен вход по email» | owner | 2026-11-21 |
| Критерий приёмки | Проверяемое утверждение, по которому принимается результат. | «Вход работает» | owner | 2026-11-21 |
| Spec review | Проверка полноты spec до утверждения владельцем. | `/spec-review` | owner | 2026-11-21 |
| Plan | Как исполнитель сделает spec: шаги, scope и проверки; пишется при take. | `card step add` | owner | 2026-11-21 |
| Run review | Ревью в конце забега: соответствие plan и код. | `/review` | owner | 2026-11-21 |
| Finding | Замечание ревью, оформленное отдельной карточкой. | `review finding` | owner | 2026-11-21 |
| Fix run | Обычный забег из finding-карточек после approve. | `run start --cards ...` | owner | 2026-11-21 |
