# v1.8.0 — для пользователя

- Финальное ревью перед релизом больше не теряет находки: они становятся такими же карточками, как после ревью забега, и критичная блокирует релиз.
- Если та же проблема найдена повторно, вторая карточка не появляется — важность растёт у уже открытой. Закрытая находка считается исправленной: её повтор заводит новую.
- Порядок очередей навыков теперь одинаково влияет и на предложение забега, и на список задач агента.
- Карточка без позиции не пропадает: она идёт после позиционных по важности и дате, а попав в забег — получает место в очереди.
- Добавлены проверки очередей, миграции счётчика «демон» и подписи «ждёт финального ревью».
