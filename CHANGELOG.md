# Changelog

## v2.0.0 — 19.11.2026

Переписывание вокруг одной сущности — карточки. CLI теперь называется `board`.

- Одна сущность — карточка: запрос → разбор → утверждение → задача. Человекочитаемые ID `<группа>-<номер>`.
- Очередь задач с оценкой `importance × urgency` (0–9) и ручной перестановкой.
- Забеги (`run`) из 1–3 карточек с атомарным бронированием и lease.
- Worktree на исполнителя и ветка на карточку; `finish` проверяет `scope` и мержит в `dev`, `release` — в `main`.
- Пакетное ревью с вердиктами `done`/`reopen` и находками трёх уровней; `critical` блокирует `main`.
- Журнал решений (`decisions.md`) и живой документ терминологии (`terminology.md`).
- Терминальная доска `now` с вкладками 0–3.
- Owner-карточки закрываются одной командой без брони и мержа.
- Все команды принимают `--json`; коды выхода 0/1/2/3.

Старый `toolbox-al` (фичи, этапы, планы, рутины, календарь, пул, профайлер и т.д.) удалён. Код сохранён в истории git; миграция старых баз `.toolbox-al` не выполняется.

## v1.0.2 — 16.11.2026

- Плагин запускал CLI через `process.execPath`, а внутри OpenCode это сам `opencode`, не Node. Теперь берётся Node, а при его отсутствии выдаётся понятная ошибка вместо вывода чужого CLI.

## v1.0.1 — 16.11.2026

- Плагин находит локальную копию инструмента по пути `tools/toolbox-al/bin/toolbox-al.ts`: версия фиксируется submodule, без переменных окружения.
- Булевы флаги больше не съедают команду: `toolbox-al --json now` работает.

## v1.0.0 — 16.11.2026

Первая версия. Инструмент работает локально: очередь, git, shaping, рутины и интеграция с OpenCode.

### Очередь

- Запросы → фичи → этапы → задачи. Задача без DoD, размера, навыка и области файлов не создаётся.
- Рука исполнителя: резервирование задач, пополнение по фиче и этапу, детерминированный порядок.
- Аренда с TTL, потолок попыток, эскалация владельцу после третьей неудачи.
- Классы обслуживания: `expedite` с лимитом 1 и записью вытеснения, `fixed_date`, `standard`, `intangible`, `quick`.
- Зависимости на трёх уровнях (задача, этап, фича) с проверкой циклов.
- Вопросы владельцу отдельно от решений; `inbox` и рука владельца сортируются по сроку.

### Git

- Ветка и worktree на фичу (`feature start`), коммит на задачу.
- Коммитит приложение, не агент, и только файлы в пределах области задачи. Изменения вне области отвергаются.
- Слияние этапа в `dev` только после закрытия задач и зелёной проверки.
- Конфликт отменяет слияние, оставляет дерево чистым и создаёт срочную задачу.
- Релиз: changelog из метаданных, semver, тег, слияние `dev` в `main`.
- Pre-commit хук не пускает прямые коммиты в `main` и `dev`.

### Shaping

- Планы версионируются; утверждение фиксирует автора и время.
- `plan apply` — одна транзакция: неполный шаг отменяет всё.
- Ревью как вердикт: автор не ревьюит себя, отклонение требует причины.
- Приёмка этапа владельцем; переоткрытие задачи снимает приёмку.
- Идеи с повышением до запроса, журнал решений, шаблоны и поиск похожих фич.

### Рутины

- Расписание `daily` / `weekly` / `every Nd`, окно исполнения, догон пропущенного за сутки.
- Шаги агентские и механические; гейты `capability`, `check`, `approval` (в том числе одноразовые).
- Тикер идемпотентен, эскалация одна на три заблокированных прогона.
- Календарь, `friction`, планировщик Windows — выключен по умолчанию.

### OpenCode

- Плагин с инструментами `al_now`, `al_inbox`, `al_task`, `al_take`, `al_done`, `al_block`, `al_ask`, `al_answer`, `al_dispatch`, `al_review`, `al_accept` — тонкая обёртка над CLI.
- Два скилла: работа с очередью и первичная настройка проекта.
- `init` создаёт файлы идемпотентно, `AGENTS.md` не затирается, есть `--dry-run`.

### Ограничения этой версии

- Часовой пояс рутины хранится, но расписание считается по локальному времени.
- Задачи рутин берутся по id, автоматически в руку не попадают.
- Обновление версий проекта (`upgrade`) не реализовано: схема мигрирует, команды обновления нет.
- Еженедельный обзор как команда не реализован; данные для него собираются.
- Внешних уведомлений нет; автономности у оркестратора нет.
- `npm install` из git не работает: Node не обрабатывает TypeScript в `node_modules`. Установка — клон или submodule.
