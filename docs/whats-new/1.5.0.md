# v1.5.0 — для пользователя

- Версии доски нумеруются как принято в разработке: исправление, новая возможность или крупное изменение.
- Релиз не выпустит старую версию: номер должен быть новее прошлого, а тег ставится на коммит выпуска.
- Версия проекта и lock-файл обновляются одной командой и не расходятся.
