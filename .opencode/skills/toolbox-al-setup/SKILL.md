# Первичная настройка toolbox-al

`init` создал только скелет. Настройку выполняешь ты: CLI не знает проект, а ты знаешь.

## 1. Посмотреть, что есть

- `AGENTS.md`, `README.md`, `docs/` — как проект устроен.
- Все `BACKLOG.md`, `TODO.md`, `TASKS.md`, экспорт issue — **все**, включая вложенные каталоги.
- `git branch -a` — есть ли `dev` или `develop`.
- `.opencode/` — есть ли уже агенты и скиллы, чтобы не перезаписать.

## 2. Предложить владельцу, не делать молча

Покажи таблицу: путь, сколько пунктов, куда переносим.

- По умолчанию найденное переносится в **идеи**, а не в задачи: задача без DoD нарушает правило.
- Ветку `dev` не создавай без вопроса: спроси, от чего её сделать.
- Состав команды: оркестратор и хотя бы один исполнитель с навыками.

## 3. Выполнить

```bash
node bin/toolbox-al.ts executor add worker-all --skills backend,frontend,content,design
node bin/toolbox-al.ts idea add "пункт из бэклога"
```

Ничего не удаляй и не переписывай в исходных файлах.

## 4. Проверить

`node bin/toolbox-al.ts doctor` — незавершённая настройка видна там.
